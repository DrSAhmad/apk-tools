APK questions, answered plainly

What is an APK file?

APK stands for Android Package Kit. It’s the file format Android uses to install an app — the equivalent of an .exe installer on Windows. Every app on the Play Store is delivered as an APK (or app bundle) under the hood.

Is it safe to install APKs from outside the Play Store?

It can be, but only from sources you trust. Check the file with the Analyzer above, review its permissions with the Risk Checker, and be wary of apps asking for SMS, accessibility or device-admin access they don’t need.

Why does an app say “not compatible with your device”?

Usually the app’s minimum Android version is higher than your phone’s version, or it needs hardware (like a specific chip or NFC) your phone lacks. Run the Compatibility Checker to see the version side in seconds.

Are my files uploaded when I use the Analyzer?

No. The Analyzer reads the file entirely in your browser using the File API and Web Crypto. Nothing leaves your device, and closing the tab clears everything.
